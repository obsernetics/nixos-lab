# nixos-lab

A hands-on lab for the Obsernetics blog series on **Nix and NixOS** for
**reproducible infrastructure**: declarative environments and systems that build
exactly what you describe and roll back with a single command.

> Everything here is built and tested in a real VM lab; the posts use real
> screenshots from these runs.

## Series
1. [Concepts, install, and the Nix store](https://obsernetics.com/blog/nixos-part1)
